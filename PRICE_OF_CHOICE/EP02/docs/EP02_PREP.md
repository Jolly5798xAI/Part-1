_Дата проверки: 2026-11-06._

## 1. Где лежит первая серия

На `main` есть только `README.md`. Материалы EP01 лежат в двух ветках. Это **две независимые версии** в разных стилях:

| Ветка | Стиль | Что готово | Видео |
|---|---|---|---|
| `claude/price-of-choice-ep01-visuals-c8i0qa` (последняя, 03:44, «approval sheet») | **низкополигональный блочный 3D**, по `reference/style_reference_01.jpg` | 21 иллюстрация + 4 анимации, референсы персонажей, SFX, микс, субтитры, монтажный лист, пайплайн рендера | MP4 собирается скриптом, в git не хранится (`renders/*.mp4` в .gitignore) |
| `claude/price-of-choice-ep01-cs5d64` (раньше, 02:37) | фотореализм | звук, стемы, субтитры (.srt/.ass), UI телефона, промпты, библии персонажей и локаций, аниматик | 30 кадров **не сгенерированы** (не было AI-генератора), есть только `EP01_ANIMATIC_PREVIEW.mp4` |

**EP02 основан на блочной 3D-версии.** Только в ней есть реальные кадры, и её стиль совпадает с вашим референсом.
Фотореальную версию используем как источник текстов: транскрипт, долгосрочная континуити, открытые сюжетные линии.
Частный репозиторий `Jolly5798xAI/price-of-choice` не открывался в этой сессии. По записи EP01 в нём только `README.md`.

Файлы EP01 в обеих ветках **не изменялись**. Всё для EP02 лежит отдельно, в `PRICE_OF_CHOICE/EP02/`.

## 4. Что изменено в скопированных скриптах (копии EP02, оригиналы EP01 не тронуты)

* `import timeline_ep01` заменён на `timeline_ep02`. Выходные файлы называются `mix_ep02.wav`, `music_ep02.wav`, `EP02_PRICE_OF_CHOICE*.srt/mp4`.
* В `06_render_video.py` убраны жёстко прописанные тайминги обратного отсчёта EP01 (68,58 / 69,96 / 10 с). Теперь они берутся из `TL.COUNTDOWN`.
* `phone_ui.py` при прямом запуске рендерит превью всех состояний `PHONE` из таймлайна в `renders/ui_preview/`.
* Новые скрипты: `00_check_vo.py` (проверка новой озвучки, только чтение) и шаблон `timeline_ep02.py`.

## 5. Что нужно для продолжения

1. **Озвучка EP02.** Одобренный MP3 от ElevenLabs тем же голосом, положить в `audio/` (см. `audio/README.md`).
2. **Текст/сценарий EP02.** Желательно сразу, чтобы проверить распознавание и разметить кадры.
3. **Решение по адресу:** кв. 47 или кв. 37.
4. Модель Whisper для `01_transcribe.py`. HuggingFace из среды заблокирован. В EP01 использовалась faster-whisper small
   из npm-пакетов `@skillninja/shortmovie-telop-model-p0…p3` (см. README ветки visuals).
5. Потом по шагам: `00_check_vo` → `01_transcribe` → заполнить `timeline_ep02.py` и добавить кадры `E2_*` в `shots.js` →
   `02_render_illustrations` → `04_sound` → `05_subtitles` → `06_render_video`.

Чего в EP02 не показывать (из континуити EP01): правила игры, откуда двойники, роль Алекса. Комната 204 и угроза сестре
появятся позже, раскрывать их только по вашему решению.
